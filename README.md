# YT Gemini v1.0.0 — Creator OS by Studio Mogli

A dedicated 5-tab Android Creator OS built to eliminate analysis paralysis and help creators ship more videos:
1. **Radar:** Accountability dashboard, Watch-vs-Create stats, Binge-to-Build flip, Streak & Achievement Badges, and Creator Setup Profile.
2. **Workbench:** Max-3 active projects, Voice-to-Script dictation, Click-to-Confirm 15s Hook generator, and No-Repeat Title/Thumbnail packaging checks.
3. **Gemini Lab:** Isolated Google Gemini WebView (zero API key required) + optional Direct API Key mode + 1-tap Export to Workbench.
4. **Assets:** Local Face / Mask / Brand gallery for consistent thumbnail generation.
5. **Studio:** Isolated YouTube Studio dashboard (`studio.youtube.com`).

Built by **Studio Mogli** ([studiomogli.com](https://studiomogli.com)).
